# Arena Strike

3D шутер у браузері (three.js), встановлюється як веб-додаток.

## Карти
- **Арена**: власна процедурна карта.
- **Офіс (CS)**: геометрія `cs_office` з [ReagentX/decompiled-csgo-maps](https://github.com/ReagentX/decompiled-csgo-maps), перетворена на прості блоки (`maps/office.json`).

## Моделі
- Ножі (`models/knife_*.json`) з [SamJUK/CS3D](https://github.com/SamJUK/CS3D) v1.0.0.
- Решта зброї зроблена вручну з примітивів.

## Примітка про авторські права
Оригінальні карти та моделі належать Valve Corporation (Counter-Strike). Ці репозиторії не мають ліцензії, тож використання для публічного проєкту на власний ризик.
